# Laundry Website
## Project Overview
This project is a simple Laundry Service landing page created using HTML and CSS.  
It includes:
- Navigation bar
- Logo section
- Navigation links
- Username section
- Hero section
- Laundry service image
- Styled button
# Features
- Responsive navigation bar
- Inline-block layout design
- Hover effects on navigation links
- Styled hero section
- Button styling
- External CSS styling
